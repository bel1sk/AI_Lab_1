### 12. Объясните различие между вызовами fit, transform и fit_transform на примере вашей программы.
* **Где в коде:** **Cell 9**
* **Ответ:**
  - `fit`: рассчитывает параметры преобразования на переданных данных (для `StandardScaler` — математическое ожидание $\mu$ и стандартное отклонение $\sigma$; для `PCA` — ковариационную матрицу, собственные значения и собственные векторы).
  - `transform`: применяет вычисленные параметры к данным: $z = \frac{x - \mu}{\sigma}$ (или умножает на матрицу собственных векторов в PCA).
  - `fit_transform`: объединяет оба шага за один проход — сначала обучается на данных (`fit`), затем сразу возвращает преобразованные данные (`transform`).

### 17. Покажите код расчёта VIF. Какие данные передаются в эту функцию? Как вы интерпретируете полученные значения VIF?
* **Где в коде:** **Cell 7**
```python
from statsmodels.stats.outliers_influence import variance_inflation_factor

scaler_for_vif = StandardScaler()
X_vif_input = scaler_for_vif.fit_transform(X_features)
vifs = [variance_inflation_factor(X_vif_input, i) for i in range(X_vif_input.shape[1])]
```
* **Ответ:**
  В функцию передается стандартизированный массив признаков `X_vif_input`.
  Формула: $VIF_j = \frac{1}{1 - R^2_j}$, где $R^2_j$ — коэффициент детерминации при регрессии $j$-го признака на все остальные.
  Значения:
  - `mileage`: $VIF = 2.2227$ ($R^2_{aux} = 55.0\%$)
  - `year`: $VIF = 2.1481$ ($R^2_{aux} = 53.5\%$)
  - `tax`, `mpg`, `engineSize`: $VIF < 1.36$
  Интерпретация: $VIF > 2.0$ указывает на наличие умеренной мультиколлинеарности между пробегом и годом выпуска (более половины их дисперсии дублируется).

### 31. Если RMSE рассчитывается через MSE, покажите соответствующее преобразование.
* **Где в коде:** В scikit-learn 1.4+ используется встроенная `root_mean_squared_error`.
* **Ответ:**
  Через MSE преобразование выглядит как извлечение квадратного корня:
  $$RMSE = \sqrt{MSE} = \sqrt{\frac{1}{n} \sum_{i=1}^n (y_i - \hat{y}_i)^2}$$
  В коде на Python:
  ```python
  from sklearn.metrics import mean_squared_error
  import numpy as np
  rmse_val = np.sqrt(mean_squared_error(y_test, y_pred))
  # или в более старых версиях sklearn:
  # rmse_val = mean_squared_error(y_test, y_pred, squared=False)
  ```

### 33. Есть ли в целевой переменной нулевые или близкие к нулю значения? Как вы учитываете их при интерпретации MAPE?
* **Где в коде:** Проверено по статистикам в **Cell 3**
* **Ответ:**
  В формуле $MAPE = \frac{100\%}{n} \sum \left|\frac{y_i - \hat{y}_i}{y_i}\right|$ в знаменателе стоит фактическая цена $y_i$. Если $y_i \to 0$, ошибка взрывается до бесконечности.
  В нашем датасете минимальная цена автомобиля составляет **£1 200** ($min(price) = 1200$). Нулевых или околонулевых значений нет вообще. Поэтому расчет MAPE стабилен и абсолютно корректен.
